# Instaltech Website

Institutional one-page website developed for Instaltech

---

## About

This project consists of a responsive institutional website designed to showcase Instaltech's services, portfolio, and company information.
The main goal is to provide a clear user journey and encourage contact through WhatsApp and e-mail.

---

## Technologies

- HTML
- CSS
- JavaScript

---

## Features

- Responsive layout (mobile-first approach)
- Sticky header with responsive hamburger menu for mobile navigation
- Fixed WhatsApp contact button
- Service presentation using cards
- Portfolio section
- Smooth Navigation between sections
